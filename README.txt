SITE CORRIGIDO — VERCEL

Este projeto foi feito para funcionar mesmo que o Vercel/GitHub não carregue pastas de CSS ou imagens.
O index.html é AUTÔNOMO: CSS e fotos estão embutidos no próprio HTML.

Envie TODOS os arquivos para a raiz do repositório.
O arquivo index.html deve ficar diretamente na raiz.

Não é necessário instalar Bootstrap, Node ou executar build.
No Vercel, use um projeto estático/Other, sem build command e com a raiz como diretório de saída.
